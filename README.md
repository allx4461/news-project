# первый этап работы: исследование и обработка данных 
### цель этапа
получить готовый набор данных, где строка соответствует моменту принятия решения: 
информация, `decision time -> entry at day's Open -> exit at day's Close` 

(дневная постановка выбрана поскольку yfinance не позволяет экстрактировать точную цену в определенный момент дня, только цену входа, выхода, high & low)
### план работ
1. сделать паспорт данных FNSPID, узнать
    - размер таблицы
    - информацию о столбцах
    - период дат 
    - информацию о пропусках/дубликатах
    - часовой пояс и вид timestamp
    - количество уникальных тикеров
    - количество уникальных источников 
2. аналогично узнать больше про yfinance 
    - даты и таймзона
    - время Open & Close
    - какие пропуски
    
3. конвертировать данные FNSPID из исходного пояса в часовой пояс UTC
4. обработать пропуски и дубликаты, оставить только акции NVDA
5. подготовить цены и торговый календарь 
    не допустить утечек информации, распределить информацию по торговым дням, 
    то есть для каждой новости определить `decision_date`
    по правилу `decision_time = 16.00 NYK` 
    - новость вышедшая до 16.00 доступна в тот же торговый день
    - новость после 16.00 относится к следующему торговому дню
    - нерабочие дни относятся к ближайшему торговому дню
    decision_date -> next_trading_date
6. посчитать `target return = close[next_day]/open[next_day] - 1`
7. зафиксировать результат в файлах 

### структура 
в папке `/scripts` будут скрипты `data_exploration` для составления паспортов данных, `download_data` для потоковой загрузки датасета (если делать все 15гб разом, произойдет переполнение оперативной памяти),`filter_data` для обработки пропусков и правильного датирования,`assemble_data` для сборки итогового датасета `новости + цены`
